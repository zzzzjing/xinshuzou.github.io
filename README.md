# Xinshu Zou 个人主页

网址：https://你的用户名.github.io

## 文件说明（全部放在仓库最外层，不需要文件夹）

- `index.html`：页面内容（英文在 `class="en"`，中文在 `class="zh"`）
- `style.css`：样式
- `main.js`：结冰、冰花、碎冰动画和页面交互
- `publications.js`：论文列表，加论文只需要改这个文件
- `photo.jpg`：个人照片（上传后主页自动显示；没有这个文件时照片位置自动隐藏）

## 更新方法

在 GitHub 上点开要改的文件，点铅笔图标编辑，改完点 Commit changes；
或者点 Add file → Upload files 上传同名文件覆盖，几分钟后网站自动更新。

其他图片也直接上传到最外层，页面里用文件名引用即可。
