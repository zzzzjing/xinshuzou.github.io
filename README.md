# Xinshu Zou 个人主页

网址：https://你的用户名.github.io

## 文件结构

- `index.html`：页面内容（中英文文字都在这里，英文在 `class="en"`，中文在 `class="zh"`）
- `css/style.css`：样式
- `js/main.js`：结冰、冰花、碎冰动画和页面交互
- `js/publications.js`：论文列表，加论文只需要改这个文件
- `images/`：图片，个人照片命名为 `photo.jpg`

## 更新方法

在 GitHub 上点开要改的文件，点铅笔图标编辑，改完点 Commit changes；或者把本地改好的文件上传覆盖。几分钟后网站自动更新。
